# Практическая работа 2

Проект написан на C++ и посвящен базовым алгоритмам криптографии:
модульным вычислениям, расширенному алгоритму Евклида и шифру Эль-Гамаля.

## Выполненные задания

1. **Теорема Ферма и двоичное возведение в степень**
   - вычисление `a^x mod p`;
   - проверка простоты модуля;
   - проверка условий применения теоремы Ферма;
   - второй способ вычисления через двоичное разложение степени.

2. **Расширенный алгоритм Евклида**
   - нахождение коэффициентов `u` и `v`;
   - вычисление числа `d`, для которого выполняется `c * d mod m = 1`;
   - вывод промежуточных вычислений и таблицы.

3. **Взаимно обратное число по модулю**
   - нахождение `c^(-1) mod m`;
   - проверка существования обратного числа;
   - вывод шагов расширенного алгоритма Евклида.

4. **Шифр Эль-Гамаля**
   - шифрование текста из консоли;
   - расшифрование пар чисел из консоли;
   - шифрование файлов;
   - расшифрование файлов.

Дополнительно в проекте есть документы по темам:

- `zadanie5` - атака посередине;
- `zadanie7` - стандарты современной криптографии в РФ.

- `zadanievse/mod` - вычисление степени по модулю;
- `zadanievse/euclid` - расширенный алгоритм Евклида;
- `zadanievse/elgamal` - основные функции алгоритма Эль-Гамаля;
- `zadanievse/proc_console` - работа с текстом из консоли;
- `zadanievse/proc_file` - работа с файлами;
- `zadanievse/optional` - вспомогательные функции.

## Сборка проекта

Для сборки используется `Makefile`.

```bash
make
```

После сборки появляется исполняемый файл:

```bash
praktik2
```

## Запуск

```bash
./praktik2
```

После запуска открывается меню:

```text
1 - Ферма, Двоичное возведение в степень
2 - Расширенный Алгоритм Евклида
3 - Вычисление взаимно обратного числа по модулю
4 - Шифр Эль-Гамаля
0 - выход
```

## Очистка

```bash
make clean
```

## Пример параметров для Эль-Гамаля

Для учебной проверки можно использовать:

```text
p = 257
g = 3
Cb = 13
k = 7
```

`Cb` - секретный ключ получателя. Открытый ключ `Db` вычисляется программой.

## Работа с файлами

При шифровании файл читается побайтно. Каждый байт преобразуется в пару чисел
Эль-Гамаля `(a, b)`. Зашифрованный файл записывается в бинарном виде.

Пример:

```text
image.png -> encrypted.bin -> restored.png
```

Для успешного восстановления файла нужно использовать тот же секретный ключ,
который был выбран при шифровании.
